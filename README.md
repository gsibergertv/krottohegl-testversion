# krottohegl-testversion

Testversionen von **Krottohegl** – einem Aufbau- und Überlebensspiel, gebaut mit Godot 4.7.
Baue ein Dorf auf, versorge die Bewohner und halte im Endsturm so lange wie möglich durch.

## Aktuelle Version

**0.9.9.53** – Download unter [Releases](https://github.com/gsibergertv/krottohegl-testversion/releases/latest).

## Steuerung (Grundlagen)

| Taste | Aktion |
|-------|--------|
| W / A / S / D | Laufen |
| E | Interagieren / Entnehmen |
| ESC | Menü / Zurück |

## Feedback

Rückmeldungen zur Testversion sind willkommen – bitte als [Issue](https://github.com/gsibergertv/krottohegl-testversion/issues) melden
und dabei die Versionsnummer (steht im Hauptmenü unten links) angeben.
